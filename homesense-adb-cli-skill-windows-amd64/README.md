# HomeSense ADB CLI Skill Package

This directory mimics a Windows skill release package.

## Contents

- `SKILL.md`: instructions the AI client can load directly
- `adb-cli.cmd`: local launcher in place of a packaged `.exe`
- `run.bat`: quick manual test entry
- `run_cmd.ps1`: PowerShell helper

## Notes

In a real release, `adb-cli.cmd` can be replaced by `adb-cli.exe` built from
`D:\files\HomeSense\homesense-adb-cli-source`.
