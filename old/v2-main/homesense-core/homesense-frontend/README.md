# HomeSense Frontend

Vue 3 + Vite frontend for the HomeSense local smart-home agent.

## Tech Stack

- Vue 3
- Vite
- TypeScript
- Naive UI
- Pinia

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

The frontend is expected to talk to the local backend under `/api`.
Adjust `.env` for your local environment if needed.
