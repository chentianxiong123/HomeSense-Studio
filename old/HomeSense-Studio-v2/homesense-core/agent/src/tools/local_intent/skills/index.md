# Local Intent Skills Index

## Tool role
local_intent 是 Fast Layer 的轻语义归一层，负责把不完全精准的表达收敛到稳定 intent。

## What it is good at
- 轻量意图归一
- 上下文补全（如“它/那个设备”）
- 输出结构化 intent 和 actions

## What it is not for
- 不负责深度推理
- 不负责长链规划
- 不负责首次复杂问题求解
